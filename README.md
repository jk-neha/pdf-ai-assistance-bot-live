# 📄 PDF Chatbot using AI

This is a Streamlit-based PDF chatbot that allows users to upload a PDF and ask questions based on its content.

## 🚀 Features
- Upload PDF
- Ask questions from PDF
- AI-powered answers using Groq LLaMA 3
- Fast response chatbot

## 🛠️ Tech Stack
- Python
- Streamlit
- Groq API
- PyPDF2

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
